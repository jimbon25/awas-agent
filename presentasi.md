AWAS AGENT adalah AI assistant berbasis terminal (TUI) dan gateway daemon (Telegram & Discord) yang saya bangun menggunakan Go.

Key:
- Interactive Terminal UI (TUI) dengan auto-complete file (@file) dan slash commands.
- Remote Gateway: Kontrol agent via Telegram atau Discord.
- SQLite Session Storage: Penyimpanan sesi lokal per-pengguna yang aman.
- 4 Mode Reasoning Agent: safe, auto, chat, dan planned/deep.
- Cross-Platform: Linux, macOS, dan Windows.
- Proxy router support (favorit kalian)
Ya mirip agent sebelah tapi punya saya masih support 2 gateway saja.

Install:
npm install -g awas-agent
