# Security Policy

## Reporting Security Issues

If you discover a security vulnerability or flaw in AWAS, please report it responsibly instead of opening a public GitHub issue.

* **Email**: Contact maintainers directly via `luisaditya90@gmial.com`
* **GitHub**: Open a **Private Security Advisory** under repository **Security** tab > **Report a vulnerability**

We aim to acknowledge all security reports within 48 hours and issue fixes in upcoming releases.
